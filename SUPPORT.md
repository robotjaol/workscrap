# Support

Career Pulse is a community-maintained open-source project and does not provide
a guaranteed support SLA.

- Read the [README](README.md) for installation, configuration, and common
  troubleshooting steps.
- Search [existing issues](https://github.com/robotjaol/workscrap/issues) before
  filing a new report.
- Use the bug report form for reproducible defects and the feature request form
  for proposed behavior changes.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

Questions about a company's hiring process, vacancy legitimacy, application
status, or ATS availability must be directed to that company. Career Pulse is
not affiliated with the employers or job platforms listed in its directory.
