# Changelog

All notable changes to Career Pulse will be documented in this file. The
project follows [Semantic Versioning](https://semver.org/) and the structure
recommended by [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Automated repository validation, tests, and extension packaging.
- Continuous integration for supported Node.js versions.
- Contributor, security, support, architecture, and development guides.
- GitHub issue forms and a pull request template.
- Reusable configuration validation shared by the settings page and tests.

### Changed

- Standardized all user-facing copy and runtime messages in English.
- Restricted configurable career sources to HTTPS.
- Clarified the project scope, privacy model, permissions, and limitations.
